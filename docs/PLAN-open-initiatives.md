## Часть 2 — Contradiction Detector: работа с ограничением precision

Полная методология, счётчик отклонённых попыток и обоснование default-исхода Этапа C — в архиве (`archive/PLAN-contradiction-precision-roadmap.md`).

### Текущее состояние (2026-07-31)

- Blocking-датасет (73 пары, enforced CI-gate): **65.8%**, без изменений с момента расширения — ноль регресса за все прошедшие правки.
- Extended-датасет (129 пар, tracking-only): **55.0%** — путь 53.4% → 54.3% → 55.2% → 54.3% (после Примера B, честно ниже — сложнее материал) → 55.0%.
- Счётчик отклонённых попыток Этапа A: **0/3** — все три реализованных узких сигнала (shared-subject-conflict, «уязвимость», частотный паттерн «прода») оказались успешными, ни разу не сорвано.

### Этап A — узкие независимые сигналы (продолжается органически)

**Действие:** при разборе новых пропущенных/ложных срабатываний — новый независимый сигнал через `max()`, не правка существующих весов. Каждая попытка проверяется через `scripts/compare_contradiction_precision.py` на обоих датасетах перед принятием. Три оставшихся разобранных, но не форсированных пропуска (`MAC-2026-0624-001` vs `STR-2026-0623-004` и два других) — открыты, нет чистого общего термина без натяжки на момент последнего разбора; пересматривать при появлении новых похожих сигналов, не форсировать сейчас.

### Пример B — рост Golden Dataset (продолжается органически)

**Статус:** 129 пар, все сигналы имеют хотя бы одну пару (полное покрытие на момент последнего батча). N=150 из ADR-012 не достигнут — сознательно, дальнейший рост потребовал бы пар низкой уверенности.

**Действие:** гибрид — постоянный ручеёк через чеклист Шага 8 CLAUDE.md (однозначные решения Шага 5 → golden-пара тем же коммитом) + периодические батчи, когда накопится достаточно сигналов без единой golden-пары (проверять командой поиска непокрытых сигналов по кластерам, как в последнем батче).

### Триггеры пересмотра (без изменений от архивного плана)

- N=3 подряд отклонённых попытки Этапа A без единого успеха → явный разговор об Этапе C (см. архив — default-исход: не эмбеддинги, пока финальный гейт — человек на Шаге 5).
- Extended <45% (sanity floor) — уже enforced тестом, немедленное расследование при первом красном прогоне.
- N=150 — честный пересчёт precision, тем же протоколом, что применён к переходу 73→116→129.
